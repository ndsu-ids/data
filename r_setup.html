古いバージョンのものがインストールされている場合

  • WindowsのRは上書きインストールされずに古いものが残るので、特別な理由がなければ事前にアンインストールする
  • RStudioの設定は、古いものがインストールされている場合は不要

Rのインストール

  • R-X.X.X for Windowsのページを開く（X.X.X はバージョン番号）
  • Download R-X.X.X for Windows のリンクをクリックして、ファイルをダウンロード
  • ダウンロードしたファイルをダブルクリックし、すべてデフォルトのまま、はい、OK、次へなどでインストール
  • デスクトップにショートカットが作られるが、削除しても大丈夫

Macの場合

  • R for macOSのページを開く
  • R-X.X.X-arm64.pkgのリンクをクリックしてダウンロード
  • ダウンロードしたファイルをダブルクリックし、画面の指示通り、カスタマイズなしでインストール

RStudio のインストール

  • RStudio IDE User GuideのページのDirect Downloads (Open Source)のセクションからWindows 11のファイル（Rstudio-X.X.X-X.exe）をダウンロード
  • ダウンロードしたファイルをダブルクリックし、すべてデフォルトでインストール
  • スタートメニューにアイコンができるので、クリックして立ち上がるか確認
  • Choose R Installation というウィンドウが現れることがあるが、デフォルトのままOKで大丈夫
  • 終了は単にウィンドウを閉じるか、あるいはq()と入力してSave workspace image? [y/n/c]というメッセージが現れたらn

Mac の場合

  • RStudio IDE User GuideのページのDirect Downloads (Open Source)のセクションからmacOS 14+のファイル（Rstudio-X.X.X-X.dmg）をダウンロード
  • ダウンロードしたファイルをダブルクリックし、現れた画面でRStudioアイコンをApplicationsアイコンにドラッグしてインストール
  • SpotlightやApplicationフォルダを使い、立ち上がるか確認
  • 終了はcommnad + Qでウィンドウを閉じるか、あるいはq()と入力してSave workspace image? [y/n/c] というメッセージにn
  • コマンドラインデベロッパツールをインストールしますかというウィンドウが現れることがある（消す方法あるとのことだが、うまくいかない模様）。インストールは環境によっては20分以上かかるので、余裕があるときに行う

RStudio の設定

  • RStudioを立ち上げ、メニューバーのTools>Global Options…を選択
  • 現れたウィンドウの最初の画面（左General内のBasicタブ）で以下のチェックボックスをオフ
    • Restore most recently opened project at startup
    • Restore previously open source documents at startup
    • Restore .RData into workspace at startup

  • 同じ画面で
    • Save workspace to .RData on exitでNeverを選択
    • Always save history (even when not saving .RData)のチェックをオフ
  • Mac の場合はGraphicsタブに移り、BackendでAGGを選択
  • 左メニュCodeのEditingタブに移り、Use native pipe operator, |> (requires R 4.1+)のチェックをオン
  • OKで終了
  • MacでPermission Deniedというエラーが出た場合は、この記事に従ってフォルダを作成する
